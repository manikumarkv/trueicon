# TrueIcon

TrueIcon is an [MCP](https://modelcontextprotocol.io) server that lets AI coding assistants search the icon packages actually installed in your project (`react-icons`, `lucide-react`, `@heroicons/react`) instead of guessing icon names. It runs over stdio, reads the exact installed versions, and returns real, importable icon names so generated code compiles the first time.

> Status: early setup. Full documentation will come with the first working release.
